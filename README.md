# Murshidabad Betar Shrota Paribar: website

Plain HTML, CSS and photos. No build step, no cookies, no third-party requests (fonts are bundled).

## Preview locally
Open `index.html` in a browser.

## Publish (GitHub Pages, free)
1. Create the GitHub account/organisation for the group (use the group's email) and a **public** repository.
2. Upload the contents of this folder (not the folder itself) to the repository's main branch.
3. Repository Settings → Pages → Source: "Deploy from a branch" → main / root.
4. The site appears at `https://<username>.github.io` (or `/<repo-name>` for a project site).

Never upload the WhatsApp export, the chat CSV files or the media index: they contain members' phone numbers. Everything in a free GitHub Pages repository is public.
